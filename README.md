# Reaction-Cam
Tired of stiff video calls? We built a hands-free AI app that turns your body language into instant on-screen memes. Just facepalm, and the perfect reaction overlays onto your Zoom or Discord feed!
*To run this program, have the meme_cam.py and all PNG files in the same folder. Then run meme_cam.py, BOOM! You now have an app!
